# SmartSaver — Diagram Index

Static GitHub Pages site for the SmartSaver diagram set.

## What is here

- `index.html` — the figure index, download buttons and print-friendly layout
- `docs.html` — the full SmartSaver documentation with all 23 figures embedded
- `assets/` — 13 hand-authored SVG/PNG pairs, UI figures, and 5 Archify interactive/print HTML figures
- `smartsaver-diagrams.zip` — the complete bundle for sending to a groupmate

No build step, no JavaScript framework, no external fonts or CDNs.

## GitHub Pages

1. Put this `site/` folder in a repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select the branch and either the repository root or the `/site` folder, depending on where the folder sits.
5. Save; GitHub Pages serves `index.html` directly.

The `.nojekyll` file keeps the static assets untouched.

## Downloads

Every card has direct download links:

- **SVG** — vector source, best for editing or print
- **PNG** — full rendered canvas, best for slides
- **HTML** — standalone Archify figure for the interactive versions

The ZIP includes the page and all assets.
